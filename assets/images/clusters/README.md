# Cluster Radar Charts

## Instructions

Place your cluster radar chart images here with the following filenames:

- `cluster1.png` - Cluster 1 radar chart
- `cluster2.png` - Cluster 2 radar chart
- `cluster3.png` - Cluster 3 radar chart
- `cluster4.png` - Cluster 4 radar chart
- `cluster5.png` - Cluster 5 radar chart
- `cluster6.png` - Cluster 6 radar chart

## Image Requirements

- Format: PNG (recommended) or JPG
- Size: 400-600px width recommended
- Background: Transparent PNG preferred
- Quality: High resolution for clarity

## Example Usage

When a user clicks a street belonging to Cluster 3, the dashboard will display:
1. "Cluster 3" title
2. The `cluster3.png` radar chart
3. The description from `map.js`
